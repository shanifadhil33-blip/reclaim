# Reclaim audit — 8 October 2026

Live site checked logged out: https://reclaim-jet.vercel.app (landing, login, `/demo`, desktop and 390px). Code checked on `master` at `1f8065b` (10 August 2026) and re-verified in this branch. The September repo notes are still accurate on the claims, Sentry Session Replay, EOB logging, and the fingerprint `SELECT` policy. They are stale on one point: sessions are ordinary Supabase cookie sessions, which the September note already said.

This is a portfolio project. It is not a HIPAA product. Signed-in screens were read in code. This environment has no Google test account, so the upload, billing, and sign-out flows were not clicked while signed in.

Hours are rough effort to fix each item, not calendar time. The day total uses 3 to 4 focused hours a day.

## (c) Backend — 18 hours

Not changed in this pull request, except the webhook no longer prints the full JSON body (counted in (a) item 11). Billing, Polar, signup, and the auth outcome were left alone on purpose.

| # | Problem | Hours |
